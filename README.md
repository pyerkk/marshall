# marshall

Персональная bio-страница в тёмном стиле с анимированным фоном и музыкальным плеером.

## Возможности

- адаптивная карточка профиля;
- анимированный дождь;
- музыкальный плеер с перемоткой и регулировкой громкости;
- управление плеером с клавиатуры;
- поддержка `prefers-reduced-motion`;
- ссылка на Telegram.

## Запуск

Откройте `index.html` в браузере или запустите любой локальный HTTP-сервер:

```bash
python -m http.server 8000
```

После этого страница будет доступна по адресу `http://localhost:8000`.

## Структура

- `index.html` — разметка;
- `style.css` — оформление и адаптивность;
- `script.js` — плеер, дождь и анимации;
- `assets/` — изображения и аудиофайл.
